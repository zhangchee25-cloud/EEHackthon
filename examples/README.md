signals-systems-demo.pdf 是本项目制作的三页中文“信号与系统”讲义，不是教师资料。源文在 backend/make_demo.py，可用 requirements-dev.txt 中的 ReportLab 重建。

| 问题 | 位置 | 预期 |
| --- | --- | --- |
| 线性系统需要满足哪些条件？ | 文件第 1 页 | 可加性与齐次性同时成立 |
| y(t)=t*x(t) 是否线性、是否时不变？ | 文件第 2 页 | 线性，但不是时不变 |
| y(t)=x(t+1) 为什么不是因果系统？ | 文件第 3 页 | 依赖未来输入 |
| 本课考试时间、教室和任课教师是谁？ | 无依据 | 明确材料不足，不编造 |
