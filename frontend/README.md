# 知页 · A 前端交付

依据 `学习Agent-双电脑三小时分工.md` 实现 A 的界面、卡片和 API 对接；界面与工作流参考用户指定的 [Heptabase Work with AI](https://wiki.heptabase.com/work-with-ai) 公开说明和官方截图。使用 React + TypeScript + Vite，PDF.js 渲染原 PDF。没有复制 Heptabase 主应用源码或品牌素材。

## 启动真实联调页面

需要 Node.js 20.19+（20.x）或 22.12+（已在 Node 25.5.0 验证）；第一次安装需要网络。

```sh
cd /Users/thuee25/Desktop/EEHackthon/frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173` 查看首页，点击「开始我的学习」进入工作台；也可直达 `http://127.0.0.1:5173/#study`。后端应在本机 `http://127.0.0.1:8000` 运行。换地址时复制 `.env.example` 为 `.env.local`，调整 `BACKEND_URL` 后重启前端。代理目标是服务端配置，不应放模型密钥。没有后端时页面会显示连接失败并禁止写入，不会创建假材料或假回答。

B 的启动命令由 B 的依赖与 README 决定，A 未创建另一套 `backend/`。共用字段与确认格式见 [接口契约](../docs/api-contract.md)。

## A 已实现

- 目标与下次目标；服务连接、读取、保存和失败提示。
- 真实 `/api/materials` 上传入口，文件类型/大小预检，后端同步解析结果；新材料成功才切换。
- PDF 实际渲染、页序输入、翻页、缩放、原文件打开；点击引用定位与摘录查看。
- 「静谧书房」UI：暖白、松绿、细边框、舒适字号；材料、阅读、助手三区，保留显式 PDF 上下文、Ask AI 与理解卡片。
- 独立首页：原创 SVG 细线路径背景、学习流程示意、工作台入口；动效遵循减少动画设置，并在离屏或页面隐藏时暂停。
- 可折叠引用来源、编号与摘录；学习步骤指引；工具标签支持方向键、Home / End。
- 非流式问答、当前范围/版本、按回答段落对应引用、材料不足与请求失败保留问题。
- AI 回答转编辑草稿，须改写正文才能保存；手写与编辑卡片；来源快照保留。
- 待复习/已自检与筛选，修改正文重置待复习。
- 单 PUT 保存队列、650ms 防抖合并、失败重试、未确认状态与编辑草稿本地保护、刷新恢复。
- 导出个人 Markdown（正文、状态、材料 ID/版本、页序、摘录，不含原 PDF）。
- 专注模式收起材料栏，助手可收起；1200px 以下材料栏按需展开，900px 以下阅读／助手切换；手机主要文本输入框 16px。
- 返回首页时工作台保持挂载，已打开的卡片草稿与请求状态继续保留。

## 隔离接口测试（不能当真实演示）

仅用于验证 A 的浏览器行为。它没有模型调用、材料解析或服务重启持久化。默认真实页面 5173 仍连接 8000，不会自动切换到测试服务。


```sh

```

打开 `http://127.0.0.1:5174/#study`；工作台顶部必须出现“接口测试桩”，回答也带显眼标记。上传 `docs/acceptance/capacitors-self-authored.pdf`（仓库根目录下的自制三页材料）。问“量子计算如何纠错？”测试依据不足；问题含“失败”测试请求错误；上传文件名为 `broken.pdf` 的文件测试坏文件错误。测试服务退出即丢失状态，不能据此声称服务重启恢复通过。

单元测试验证保存顺序/合并/失败重试、卡片状态、导出、引用校验、接口错误与保存确认。浏览器实际验收记录及截图见 [A 交付与验收](../docs/frontend-A交付与验收.md)。

## 交接与限制

交接 `frontend/` 源码、`package.json`、`package-lock.json`、`.env.example`、`docs/api-contract.md` 和验收资料。无需复制 `node_modules/`；`npm ci` 会恢复依赖与 PDF 资源。`.env.local` 和密钥不进提交包。

同一学习空间只打开一个编辑页面，不做多标签并发合并。未提交的编辑草稿不会混入导出；提交到状态但后端保存失败时仍可导出当前本机内容，顶部失败提示持续保留。旧卡片来源临时打开原材料，不改变当前问答范围。

真实问答、引用是否支持结论、PDF 拒绝扫描件、磁盘持久化与后端重启恢复均需 B 服务交付后验收。A 前端测试通过不代表 D0 完整链路通过。

在仓库根目录运行 `python3 frontend/scripts/package-a.py` 可重建 `artifacts/A-frontend-handoff.zip`。此包仅含 A 源码与交接资料，不包含 B 服务、密钥、运行数据或依赖缓存。
