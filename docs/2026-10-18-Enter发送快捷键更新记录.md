# 更新记录：Enter 发送问题

日期：2026-10-18  
项目：清大搭 THU O PAL  
发布分支：`lsx`

## 改动

材料问答输入框的发送快捷键由 **Ctrl/Cmd + Enter** 调整为 **Enter**，并同步更新输入框下方的操作提示。

| 操作 | 结果 |
| --- | --- |
| Enter | 发送当前问题 |
| Shift + Enter | 在问题中换行 |
| 点击“提问” | 发送当前问题 |

此改动用于课程材料问答和独立材料问答共用的输入框。卡片正文、目标、真题关注内容等编辑框保持各自的输入行为。

## 输入保护

- 中文等输入法仍在组合文字时，Enter 用于确认输入，不触发发送；同时兼容组合输入的键码 `229`。
- 忽略长按 Enter 产生的重复键盘事件，避免连续触发发送。
- 继续保留空白问题、无可用材料、正在提问、正在上传或工作区锁定时的发送限制。
- 请求失败保留问题，重试继续复用原有请求标识。
- 回答完成时仅清空已发送的问题，不清除等待期间新编辑的草稿。

刷新正在运行的学习空间，在“材料问答”中输入问题后按 Enter；需要多行内容时按 Shift + Enter。
