# 知页 UI 改版验收

日期：2026-10-18。范围：继续上次已开始的「静谧书房」首页及工作台改版。

## 已完成

- 补齐 `frontend/src/landing.css`，解决 `main.tsx` 导入缺失样式导致的构建阻断。首页使用原创 SVG 细线路径、松绿主按钮、学习流程示意，连接现有工作台。
- `tokens.css` 统一颜色、字体、间距和圆角；`styles.css` 配套现有 React 结构，移除旧布局样式，正文 14px、回答正文 16px、主要辅助信息 11–12px。
- 1200px 以下材料栏通过按钮展开，900px 以下阅读／助手按需切换，避免手机纵向叠放两个工作面板。手机目标、问题、卡片编辑及下次目标文本输入使用 16px。
- 现有引用数据对应编号、折叠来源列表与摘录，保留真实跳页；卡片维持改写、保存、自检、筛选流程。
- 首页／工作台切换保留已挂载工作台；工具标签支持方向键和 Home / End；学习指引显示当前步骤。
- 首页路径动画支持系统减少动画设置、离屏暂停与页面隐藏暂停。

## 验证结果

- `npm run build`：通过 TypeScript 和 Vite 构建。仍有既有 PDF.js 主包体积提示及 Zod 注释提示，无构建错误。
- `npm test`：2 个文件、10 项测试通过。
- Chrome 桌面浏览器自动检查：320、390、768、900、1024、1199、1440、1920px；首页及工作台均无文档横向溢出，阅读／助手按断点显示。
- 隔离接口桩交互：上传自制 PDF、实际渲染画布、发送问题、引用跳转第 2 页、AI 草稿改写前禁用保存、改写保存、标记已自检全部通过。
- 手机布局：阅读／助手标签切换、材料栏展开、专注模式收起材料、工具标签方向键切换通过。
- 工作台中编辑草稿 → 返回首页 → 再进入工作台：草稿内容保留。
- 系统减少动画设置下，背景路径动画为 none。真实入口后端断线时显示连接失败并禁用目标编辑。
- 本轮浏览器检查未发现页面脚本异常。
