## 按顺序完成

### A1：先完成前端 API 与状态适配

集中改 `api.ts`、`domain.ts`、`useStudyState.ts` 和对应测试：

- `selectedScope` 统一为材料版本数组；课程问答只校验本次范围内引用，每条引用按它自己的材料检查，不能用当前 PDF 总页数判断全部来源。
- 状态保留 revision；PUT 带最新版本，成功读取完整新状态；去掉必须 `saved:true` 的假设。保留串行保存、合并后续编辑、失败草稿和重试。接纳服务器响应时不能覆盖请求期间的新编辑。
- 显示 `error.message`，保留 status/code/details；409 保留本地修改并提示重读／恢复，不能自动拿旧内容覆盖。
- 课程上下文包含 activeCourseId；卡片带 courseId，手动上传／未归课程内容可为 null。切换课程不串问答、卡片或白板；切换时清理旧回答并保留未保存草稿。
- 界面容量说明与健康接口 limits 一致，默认文本 PDF 5 MB／20 页。

### A2：导入和课程知识库界面

- 材料栏新增“连接网络学堂”“从网络学堂导入”。学校登录页完全由 B 提供，A 只打开契约中的本机 loginUrl 并刷新连接状态，不实现账号密码、Cookie、验证码或学校请求。
- 学期 → 课程 → 文件列表，显示支持类型／不支持原因；支持一次选择全部支持文件或子集并提交导入。
- 展示每项 pending/downloading/processing/ready/failed/needs_auth/unsupported 和真实计数；可重试失败项，失效时提示重新连接。
- 导入完成刷新课程材料列表，点击材料沿用 PDF 阅读器；显示已就绪范围与未成功项。
- 提问默认当前课程已就绪材料，也能切换单文件；展示多文件引用，点击后打开正确文件页序与摘录。

### A3：知识卡片与最小白板

- 沿用 AI 草稿 → 本人改写 → 保存 → 待复习／已自检；正文变化恢复待复习；保留来源和 Markdown 导出。
- 一门课一块板，加入该课程已保存的卡片；拖动位置、手动连接两个节点、移除节点和关联线、点击打开卡片／出处。
- 节点只保存 cardId 与坐标，正文从同一份卡片状态读取；移除节点不删除卡片。
- 拖动结束后保存；白板独立 revision 和保存队列；加载时恢复节点与线，失败保留草稿并提示重试。
- 不增加 AI 整理、自动布局、多板、复杂缩放、协作或新的设计系统。
