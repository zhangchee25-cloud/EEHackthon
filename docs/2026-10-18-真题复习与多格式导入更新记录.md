本轮在已有课程问答、学习卡片、AI 白板和卡片讨论的基础上，新增“往年真题 → 分析考点 → 回看相关知识 → 做类似练习”的复习流程，并扩展常用学习材料的导入格式。

## 一、往年真题与练习

### 真题库

- 在课程工具栏增加“真题与练习”入口。
- 可上传本机试卷，也可把课程已有材料标记为真题。
- 用户可填写年份，并选择期中、期末或其他考试。
- 真题按课程保存，排除在默认讲义问答和白板生成范围之外，避免混淆试题与知识讲解。
- 一次可选择 1–10 份试卷进行分析。

### 考点与相关知识

- AI 根据试卷片段分析考点、考查方式和复习建议，一次最多返回 12 个考点。
- 每个考点附真题摘录、文件与页码，可以点击回到阅读器核对。
- 匹配已导入讲义中的相关知识，并单独展示讲义出处。
- 真题引用与讲义引用分别校验材料归属、版本、页码和原文摘录；无法通过校验的结果不会保存为成功报告。
- 缺少讲义依据时明确提示，允许用户补充材料后重新分析。
- 根据考点与卡片标题的关键词匹配相关学习卡片，可打开卡片继续学习；匹配关系需要用户核对。

### 原创类似练习

- 可请求生成 1–5 道关联考点的原创类似题。
- 每道题包含题干、解题提示和参考解答；提示与答案默认折叠，便于先自行作答。
- 材料不足或生成结果不足时说明原因，实际题目数量可能少于请求数量。
- 页面明确标注 AI 原创练习与参考解答，不将其称为历年原题、官方答案或未来考试预测。

### 保存和重试

- 分析报告保存在本机 SQLite 中，历史列表展示最近 30 份报告；刷新或后端重启后仍可恢复。
- 分析失败保留输入，并在重试时复用请求标识，避免已成功但响应丢失时重复生成。
- 成功后再次分析使用新的请求标识，以便纳入新补充的材料。
- 文件上传成功但真题注册失败时保留上传结果，重试不必重新上传文件。

## 二、常用材料格式

课程材料、本机独立上传和网络学堂导入使用同一套格式支持规则。课程内也可直接添加本机讲义。

| 格式 | 支持方式 | 阅读与引用位置 |
| --- | --- | --- |
| PDF | 提取已有文字 | 保留原 PDF，引用文件页序 |
| Word `.docx` | 提取正文、表格等可提取文字 | 生成文字阅读版，引用重排后的阅读页序 |
| PowerPoint `.pptx` | 按演示文稿顺序提取幻灯片文字 | 生成文字阅读版，页码对应幻灯片序号 |
| Markdown `.md` / `.markdown` | 读取文本内容 | 生成文字阅读版；不完整渲染 Markdown 排版 |
| 文本 `.txt` | 支持 UTF-8、带标记的 UTF-16 及可识别的 GB18030 编码 | 生成文字阅读版，引用阅读页序 |
| 旧版 Word `.doc` / PowerPoint `.ppt` | 需要本机安装 LibreOffice 转换 | 引用转换后的 PDF 页码；未安装时提示另存为新格式 |

非 PDF 文件保留原件，并生成供现有阅读器使用的本地 PDF 阅读版。默认单文件上限 100 MB，可通过后端配置调整。

## 三、使用方法

1. 启动后端和前端，打开 <http://127.0.0.1:5173/#study>。
2. 选择课程，先通过材料库上传讲义，或从网络学堂导入。
3. 点击“真题与练习”，上传试卷或选择已有材料，填写年份、考试类型，再点击“加入真题库”。
4. 勾选需要分析的试卷，填写关注内容，选择练习题数量，点击“分析考点并出题”。
5. 查看考点，点击真题或讲义引用核对相关知识；完成练习后展开提示和参考答案。
6. 后续从“查看已保存的分析”恢复报告，或补充材料后重新分析。

升级后先在项目根目录更新后端依赖：

```bash
python -m pip install -r backend/requirements.txt
python -m backend
```

另开终端启动前端：

```bash
cd frontend
npm ci
npm run dev
```

本轮新增运行依赖 `reportlab==4.4.9`，用于生成文字阅读版。旧 DOC/PPT 的 LibreOffice 为可选本机依赖，不会自动安装。学校临时会话可能在后端重启后需要本人重新登录；已入库材料和学习记录保留。

## 四、主要代码与接口

| 位置 | 本轮职责 |
| --- | --- |
| `backend/exams.py` | 真题标记、考点与练习生成、出处校验、报告持久化和请求去重 |
| `backend/document_worker.py` | Office/Markdown/文本解析与文字阅读版生成 |
| `backend/service.py`、`courses.py`、`server.py`、`learn.py` | 通用上传、课程关联、HTTP 接口和学校文件格式适配 |
| `frontend/src/components/ExamPrep.tsx` | 真题库、分析报告、练习和历史界面 |
| `frontend/src/materialFormats.ts` | 上传格式与文件大小预检 |
| `frontend/src/App.tsx`、`api.ts`、`domain.ts` | 入口、课程上传、接口调用与返回结构校验 |
| `backend/verify_exams.py` | 仅使用自制材料的真实模型验收脚本 |

新增接口：

- `POST /api/courses/:id/materials`：通过 multipart `file` 上传课程材料。
- `GET /api/courses/:id/exams`：读取课程真题与最近的分析报告。
- `POST /api/courses/:id/exams`：将课程材料登记为真题，填写年份和考试类型。
- `POST /api/courses/:id/exams/analyze`：提交 `requestId`、`examMaterialIds`、`instruction`、`practiceCount`，生成并保存分析报告。

## 六、已知限制

- 尚不支持扫描件 OCR；图片、图表、公式和 Office 原始排版不能完整保留，需结合原件核对。
- 上下文预算不足时，只分析试卷代表片段和相关讲义片段，并提示覆盖范围；不能据此统计完整考点频率。
- AI 分析、关联知识和练习解答仍可能出错，出处校验不等于语义或计算正确性认证。
- 报告和材料仍保存于本机，未新增云同步、多人协作、自动评分或考试预测功能。
- 旧版 DOC/PPT 的支持取决于目标机器是否安装 LibreOffice；不将可选转换路径等同于所有机器均已实测。

本轮由主 Agent 与三个子 Agent 分别承担后端分析、格式解析、导入入口、真题界面和交叉验收。按用户指定，仅发布到 `lsx` 分支，未更新 `main`，未重新提交网盘。
