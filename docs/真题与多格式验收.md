# 真题复习与多格式导入验收

日期：2026-10-18。本次按用户要求仅提交到 GitHub lsx 分支，不更新 main，不提交网盘。

## 功能

- 课程本地材料上传；PDF、DOCX、PPTX、Markdown、TXT解析和可定位阅读。
- DOC/PPT依赖本机LibreOffice；本机缺失时明确提示另存格式，不假报成功。
- 真题库按课程隔离，用户填写年份、期中/期末/其他考试。真题不进入默认讲义范围。
- 选择1–10份试卷，分析考点并分别展示试卷依据、讲义知识依据；关联卡片按标题词匹配，提示自行核对。
- 生成1–5道原创类似练习，答案和提示默认折叠；不冒充原题、官方答案、命题预测。
- 分析记录保存到本机SQLite，刷新和重启后恢复；同requestId重试复用结果。
