# zch 白板体验优化记录

日期：2026-10-18。基于 `zch` 分支 `c1a860264fa943fe0eb3a71e9d979f7dde2bd712`。

## 操作方式

- 打开课程白板，在画布顶部工具栏直接点击“全屏白板”。全屏时画布填满屏幕的可用区域；点击“退出全屏”或按 Esc 返回。
- 使用“适合全部”查看所有卡片，或用加减按钮、100% 调整缩放；缩放后仍可拖动标题或用方向键移动节点。
- 在“我的理解”中，每张已保存的课程卡片右下角都有“把卡片添加到白板”。加入后显示“已在白板中”，避免重复加入。
- 新建或编辑课程卡片时，点击“保存并加入白板”，等卡片保存成功后自动上板。
- 在画布中勾选节点，点击“移出选定”；也可以在卡片列表勾选已上板的卡片，点击“移出选定卡片”。
- 点击“全部移出”并确认，清空当前课程的白板。移出操作同时移除相关连线，保留学习卡片正文、来源和复习状态，之后可重新加入。
- 全屏时点击“添加卡片”“打开卡片”或来源，会先退出全屏再打开相应区域。

## 实现要点

旧布局的画布受 `55vh`、手机端 `450px` 高度上限及固定画布尺寸限制。新增独立的 `WhiteboardViewport`，全屏时将同一画布移动到页面顶层，避开父容器裁切；浏览器不支持原生全屏时使用铺满视口的页面内全屏。

滚动区域和实际画布随可用尺寸伸展，自动适配依据真实卡片边界计算。拖动距离按缩放比例换算；手动拖动或方向键移动会退出自动适配，避免画布跟随移动重新缩放。

卡片入口复用白板已有的保存队列。保存卡片失败时不会创建悬空白板节点；课程切换、保存冲突或恢复草稿时取消待上板操作。清空白板需确认，全部操作保留原卡片。

## 验证方式

在 `frontend` 目录运行：

```sh
npm test
npm run build
npx playwright test -c playwright.whiteboard.config.ts
```

白板专项测试使用独立的本机接口测试桩，覆盖桌面（1440×900）和手机（375×812）的原生全屏、回退全屏、真实画布尺寸、退出与焦点恢复、卡片加入、批量移出、确认清空、刷新持久化、保存失败后的处理。测试不会调用学校账号或外部 AI 服务。

32 项桌面／手机界面回归、21 项前端单元测试以及生产构建通过；需真实后端配置的 3 项集成测试未执行。回归同时覆盖已有的课程隔离、AI 白板、卡片来源、保存失败恢复和版本冲突处理。桌面、手机全屏及卡片操作截图已在本机检查。
