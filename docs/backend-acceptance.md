## 对真实回答的内容复核

由编码代理对照实际 PDF 提取文本复核，不冒充独立真人评审：

1. 线性条件：回答明确“可加性和齐次性同时成立”，分别解释两项规则；四条摘录均来自文件第 1 页。
2. y(t)=t*x(t)：回答为线性但时变，正确区分输入移位与输出移位；引用第 1 页定义与第 2 页原例和时不变条件。推导步骤由这些定义得出，主要结论受原文支持。
3. 考试信息：没有编造时间、教室或教师，明确指出材料不包含这些信息。

原始成功响应、耗时、引用和 18 个检查点见 backend-verification.json。三个问题本次耗时约 10.08 秒、10.98 秒、8.11 秒，仅是这一轮观测，不承诺普遍延迟或答案质量。

## 复现与交接

~~~powershell
./backend/start.ps1
python -m unittest discover -s backend/tests -v
python -m backend.verify_live --pdf examples/signals-systems-demo.pdf
python -m backend.package_handoff
~~~

没有系统 python 命令时，按 backend/README.md 使用虚拟环境或当前电脑随附 Python。真实验收产生平台用量，不应把离线模型桩当作真实结果。
