## 实现结果

| 功能 | 交付内容 |
| --- | --- |
| 网络学堂入口 | 只打开 B 本机登录页；刷新/窗口聚焦检查连接；学期、课程、文件选择；不支持原因和目录不完整提示 |
| 一键导入 | 支持文件全选/子集；requestId 复用；2 秒查询运行中批次；逐项状态和真实成功计数；失败/认证失效重试；刷新恢复批次与课程材料 |
| 课程知识库问答 | 默认当前课已就绪材料，可选当前文件；selectedScope 数组；引用校验所属材料版本和各自页数；点击定位对应 PDF 和摘录 |
| 知识卡片 | AI 草稿必须改写；手写/编辑、复习标记、修改正文重置待复习；保留来源；按课程展示和导出；存储保留全课程卡片 |
| 学习状态 | 完整服务端状态确认、revision 串行推进；保留请求中的后续编辑；503 重试；409 停止自动写，重读后选择版本；本机草稿保护 |
| 课程白板 | 每课一板；引用已保存卡片；拖动标题/键盘移动；手动连线和关系说明；删除节点/边；打开卡片/出处；正文同步；独立 revision 与草稿恢复 |
| 课程隔离 | 问题与卡片编辑草稿按课程保留；切课清空旧回答；课程材料与白板独立加载；不把其他课程卡片重新归属 |
| 原有阅读界面 | 保留首页、PDF.js、翻页/缩放/引用、来源摘录、专注和手机阅读/助手切换；容量默认 5 MB / 20 页，支持后端 limits |

3. AI 原样正文不能直接保存；改写后保存，标记自检，改正文恢复待复习；导出 Markdown 包含正文与来源。
4. 三张卡片上板，键盘移动、桌面指针拖动、连线；刷新恢复；移除一个节点仍保留三张卡片；正文修改在板上同步。
5. A 课程未保存卡片草稿切到 B，再切回恢复；两个课程卡片仍完整保存，切课没有旧回答残留。
6. 学习状态 503 失败保留连续输入；恢复服务后重试；409 重读后明确恢复草稿，刷新仍存在。
7. 十张卡片白板；白板 503 保留草稿并在刷新后恢复；白板独立 409 重读/恢复；位置和卡片数量正确。
8. 独立上传坏文件错误、正常 PDF 真实渲染；提问错误保留问题，同问题重试沿用 requestId；改问题换 ID；依据不足明确显示。

9. 旧版浏览器问题、卡片编辑草稿、未保存学习状态迁移到课程版本；恢复并保存后刷新不反复出现旧草稿。

## 验收边界与待联调

以上导入、模型回答、存储接口均为**显著标识的隔离桩**。PDF 阅读器实际渲染的是合成的三页测试 PDF。浏览器刷新恢复已经验证，**不等于真实后端服务重启持久化通过**。

2026-10-18 17:06 左右检查 `http://127.0.0.1:8000/api/health` 无法连接。A 没有代替 B 实现学校登录、网络学堂下载、文件解析、真实模型或磁盘存储，因此下列项目仍待集成人接入 B 候选服务后验证：

- 真实登录/二次认证与课程文件获取；OneTHU 参考实现的实际可用性由 B 验证。
- 真实课程文件构建知识库；材料标题、版本、页数与引用摘录准确性。
- 真实模型输出正确性及来源是否支持回答。
- 学习状态、卡片、导入批次和白板在后端重启后的恢复。
- B 全部新增端点与固定契约一致；接口错误在正常页面保留，不回退假数据。

前端明确限制：不做 OCR、FreeBBS 接入、自动白板布局、多板协作或自动冲突合并。冲突恢复按钮会用用户选择的本机完整草稿替换刚重读的服务端版本，页面明确提示；独立上传没有全量历史查询接口，刷新仅恢复当前文件。
