# 清大搭 THU O PAL

> 把课程材料变成有出处、可改写、能持续复习的个人学习空间。

507队 · 校园学习生活赛道 · 现场关键词：**成长、专注**

队长：杨坤烨；队员：杨坤烨、张弛衡、卢汕郗。

文档整理日期：2026年10月18日。

## 解决什么问题

课程资料、AI 对话与个人笔记通常分散在不同位置：学生读完讲义后仍难以追溯答案出处，复制一段回答也不等于形成自己的理解，下次复习时还要重新寻找材料和学习进度。

清大搭把学习目标、材料阅读、问答、原文核对与理解卡片放在同一工作台。学生围绕一个具体问题学习，核对引用后用自己的话保存理解，并记录待复习内容与下次目标。**成长**体现在个人理解的积累和自检记录；**专注**体现在围绕当前目标与材料连续学习，以及可收起干扰区域的工作台。

## 必要环境

- Node.js：20.x 至少 20.19.0，或 22.12.0 及以上，版本范围以 `frontend/package.json` 为准。
- npm：随 Node.js 安装，使用锁文件恢复依赖；本轮检查环境为 Node.js 25.5.0、npm 11.8.0。
- 浏览器：现代 Chrome、Edge 或其他支持 ES Modules、PDF.js 的现代浏览器。浏览器自动化验收需要 Chrome 或 Playwright Chromium。
- 首次安装需要访问 npm 包源。前端 PDF worker、CMaps、字体与 WASM 由安装脚本复制为本地资源。
- 完整演示需要提供符合 [A／B 集成契约](docs/AB-本轮集成契约.md) 的真实后端，默认地址为 `http://127.0.0.1:8000`。后端运行时、依赖、存储目录与模型配置以实际交付的后端 README 为准，当前无法核实，不能据前端推测启动命令。
- 真实问答需要后端可访问允许使用的模型服务。API 密钥只在后端本机配置，不写入浏览器、源码、截图、对话公开副本或提交包。

## 运行方法

以下命令从**当前源码仓库根目录**执行。如果最终压缩包按手册要求将仓库内容放入“源码/”，应先进入“源码/”再执行。

### 1. 安装并启动前端

```sh
cd frontend
npm ci
npm run dev
```

首页：<http://127.0.0.1:5173>。工作台：<http://127.0.0.1:5173/#study>。

前端默认将同源 `/api` 请求代理到 `http://127.0.0.1:8000`。如后端地址不同，在 `frontend/` 中执行：

```sh
cp .env.example .env.local
```

将 `.env.local` 的 `BACKEND_URL` 改为实际后端地址，再重启前端。该配置仅用于开发／预览代理，不放模型密钥。不连接后端时可查看首页和连接失败提示；依赖服务的学习操作无法完成。

### 2. 启动真实后端

当前仓库尚无后端源码、依赖和启动入口，不能仅凭上述命令运行真实 AI 学习闭环。取得后端交付后，须将后端源码、锁定依赖、无密钥配置示例、运行命令、模型配置方式及数据保存位置一并纳入最终包，并在此处补入实际启动命令。

核对 `/api/health`、`/api/state`、材料上传与文件读取、问答等接口后，再进入正常工作台验收。涉及网络学堂和白板时，按集成契约核对课程、导入批次与白板接口；契约本身不代表接口已经实现。

### 3. 构建与检查

在 `frontend/` 目录执行：

```sh
npm test
npm run build
```

构建通过后才可执行：

```sh
npm run preview
```

预览入口：<http://127.0.0.1:4173/#study>，仍需要真实后端。不要双击 `dist/index.html` 启动，也不要将前端产物视为包含后端的完整交付。

可选的浏览器验收命令为 `npm run test:ui`，需要 Chrome；若使用 Playwright Chromium，按 [前端说明](frontend/README.md) 安装并指定浏览器。自动化验收使用测试桩时，其结果只证明对应的前端行为。

## 如何现场演示

以下为**真实后端交付并通过验收后**的两分钟核心演示流程。当前交付条件未满足时，应说明限制，展示实际可运行页面和已有源码，不将测试桩作为完整产品展示。

演示前准备：启动真实后端与前端，确认页面未显示“接口测试桩”，准备仓库内自制材料 `docs/acceptance/capacitors-self-authored.pdf`（三页电容短讲义）。关闭旧测试服务，避免代理到错误端口。

| 时间 | 操作 | 向评审说明与核验 |
| --- | --- | --- |
| 0:00–0:15 | 首页进入学习空间，填写“理解电容储能与电压的关系” | 本次围绕一个目标学习，解释“专注” |
| 0:15–0:35 | 上传自制 PDF，打开第 2 页 | 展示原 PDF 与页序；等待真实解析就绪 |
| 0:35–1:00 | 提问“电容的能量储存在哪里？”并点击引用 | 对照第 2 页 `Energy is stored in the electric field.`，核对结论、摘录、材料与页序 |
| 1:00–1:25 | 新建理解卡片，用自己的话改写后保存 | 例如“电容通过两极之间的电场储能”；确认服务保存成功，解释“成长” |
| 1:25–1:45 | 标记已自检，再修改正文；填写下次目标，导出 Markdown | 展示状态回到待复习，导出包含个人表述、来源、版本和页序 |
| 1:45–2:00 | 刷新页面，核对卡片与阅读位置 | 仅说明实际验证的恢复范围；服务重启恢复需另外停启后端验证 |

可追加材料内问题：“容量不变，电压变成两倍，储能如何变化？”对照第 2 页公式及第 3 页例子，应得到四倍。材料外问题使用“量子计算如何纠错？”，应如实报告当前材料依据不足。模型请求失败时展示错误与保留的问题，不换成预置成功答案。

网络学堂导入、多材料问答、白板只在最终候选版本真实通过后追加演示：账号本人在本机完成学校认证 → 选择课程与文件 → 等待真实导入就绪 → 核对课程问答引用 → 将卡片加入白板、连线 → 刷新并重启后端核对恢复。未通过的环节如实说明。
