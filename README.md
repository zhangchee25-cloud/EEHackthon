## 项目方向

围绕一门课程，让学生完成 **设定本次目标 → 导入讲义 → 阅读与提问 → 核对出处 → 用自己的话保存理解卡片 → 组织白板 → 标记待复习 → 下次继续**。

赛题截图给出“连接、成长、专注”三个关键词，要求作品至少与其中一个有明确关系。本项目主打 **成长**（留下自己的理解与复习记录）和 **专注**（围绕一个目标连续学习）；**连接**作为后续通过课程讨论寻找学习伙伴的延伸。知识点连线本身不等于赛题所说的同学连接。
